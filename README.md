# Sobral News

App PWA de notícias de Sobral e da região norte do Ceará, sincronizado automaticamente com sobralnoticias.com.br.

## Rodar localmente

\`\`\`bash
npm install
npm run dev
\`\`\`

## Build

\`\`\`bash
npm run build
npm run preview
\`\`\`

## Deploy

Push para `main` → GitHub Actions publica automaticamente no GitHub Pages.

## Fonte de dados

RSS do Blogger: `https://www.sobralnoticias.com.br/feeds/posts/default?alt=rss`
